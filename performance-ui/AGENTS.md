# performance-ui

This repository is an interface system for fast sites. Before writing or reviewing any UI with it, read `SKILL.md`. It holds the hard rules and says which file in `references/` to open for the detail.

Use the values in `tokens/tokens.css`, or `tokens/theme.css` in a Tailwind project. Never type a raw colour, size, space, radius or duration that a token already covers. A value that is not on a scale snaps to the nearest step.
